<a name="english"></a>
## 🇬🇧 English

A responsive weather forecast web application designed to provide real-time weather information and multi-day forecasts with a clean, intuitive user interface.

🌐 **Live Demo:** [weather-forecat-0520.netlify.app](https://weather-forecat-0520.netlify.app/)

### 🛠️ Tech Stack
- **Frontend:** React 19 + Vite , Tailwind CSS (V4)
- **API** - WeatherAPI
- **Hosting / Deployment:** Netlify

### ✨ Key Features
- **Real-Time Weather Data:** Get accurate current weather conditions for your city.
- **Multi-Day Forecast:** View upcoming weather trends at a glance.
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **Fast & Lightweight:** Built for speed and smooth navigation.

### 🔮 Future Improvements
- [ ] **Dynamic Weather Backgrounds:** Automatically change the website background/wallpaper according to the current weather condition (e.g., sunny, rainy, cloudy, snowy).

## 🇯🇵 日本語

リアルタイムの天気情報と数日間の天気予報を、シンプルで確認できるレスポンシブWebアプリケーションです。

🌐 **ライブデモ:** [weather-forecat-0520.netlify.app](https://weather-forecat-0520.netlify.app/)

### 🛠️ 使用技術 (Tech Stack)
- **フロントエンド:** React 19 + Vite , Tailwind CSS (V4)
- **外部API** -  WeatherAPI
- **ホスティング / デプロイ:** Netlify

### 工夫した点
　　いつも使っているプログラミング言語ではなくて「ReactJSとVite」という新しい言語使ったので、新しい言語を学ぶことができました。そして、初めてAPI使ったので、APIのやり方のについてもっと勉強になりました。

### 苦労した点
  新しい言語を使ったので、開発環境のためゼロから勉強しました。または、APIのレスポンスを受ける時は、期待した通りにならないでエラーが発生したので、それを解決するため時間をかかったし、GitHubの上に載せる時もあまり重要ではないファイルも含めているのでファイルのサイズも大きいし、そのために修正したので、時間がかかったことはいっぱいありました。

### ✨ 主な機能
- **リアルタイム天気表示:** お好きな都市の現在の天気を正確に取得します。
- **天気予報:** 数日間の天気の傾向を一目で見えます。
- **レスポンシブ対応:** PC、タブレット、スマートフォン等、あらゆるデバイスに最適化されています。
- **高速＆軽量:** スムーズで快適な操作感を提供します。

### 🔮 今後改善したい点
- [ ] **天候連動型背景:** 現在の天気（晴れ、雨、曇り、雪など）に応じて、ウェブサイトの背景を自動的に切り替える機能。
